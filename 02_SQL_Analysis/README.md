# SQL Analysis

## Overview

This folder contains SQL queries developed to analyse customer churn, retention behaviour, revenue patterns, and customer segments using PostgreSQL.

## Analysis Areas

- Customer churn and retention KPIs
- Churn by contract type
- Churn by tenure groups
- Churn by payment method
- Churn by internet service
- Customer revenue analysis
- Customer segmentation
- Data quality validation
- SQL joins and reference table validation
- Window functions and ranking analysis

## Tools Used

- PostgreSQL
- SQL
- Common Table Expressions (CTEs)
- Aggregate Functions
- Joins
- Window Functions

## Objective

To transform customer-level data into meaningful business insights that support customer retention analysis and business decision-making.
