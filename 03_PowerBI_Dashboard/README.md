# Power BI Dashboard

## Overview

This folder contains the Power BI dashboard developed for Customer Churn and Retention Analytics.

The dashboard presents key performance indicators, customer churn patterns, contract analysis, tenure analysis, payment behaviour, and revenue insights.

## Dashboard Highlights

- Total Customers
- Churned Customers
- Retained Customers
- Churn Rate
- Retention Rate
- Churn Analysis by Contract
- Churn Analysis by Tenure
- Payment Method Analysis
- Internet Service Analysis
- Monthly Charges Analysis

## Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX
- PostgreSQL

## Objective

To convert customer data into interactive visual insights and support data-driven customer retention decisions.

## Project Note

The dashboard is based on the IBM Telco Customer Churn customer-level dataset. The analysis is descriptive and does not represent a predictive churn model.
